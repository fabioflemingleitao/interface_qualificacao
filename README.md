Título: Visualizações Interativas – Análises Estruturais e Sísmicas
====================================================================================
Este repositório contém três arquivos em formato .html com visualizações interativas relacionadas a análises estruturais e sísmicas. 
Como são arquivos locais, eles devem ser baixados e abertos em um navegador de internet (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.) para correta visualização.

# Observação importante
Os arquivos foram desenvolvidos para visualização local. 
Portanto, eles não serão renderizados corretamente diretamente na visualização do GitHub, 
sendo necessário o download para visualização completa das funcionalidades interativas.

# Como visualizar os arquivos
1 - Baixe o arquivo desejado deste repositório.
2 - Caso o arquivo esteja compactado (.rar), descompacte utilizando o WinRAR ou software similar.
3 - Abra o arquivo .html extraído em um navegador (Chrome, Firefox, Edge, etc.).


Arquivos disponíveis:
====================================================================================

# Visualizador_Edificio3D.html
Este arquivo apresenta uma visualização tridimensional de uma estrutura de concreto armado, permitindo observar suas dimensões geométricas e características estruturais.
Para visualizar, é necessário baixar o arquivo e abri-lo diretamente em um navegador.

# Mapa_ComparacaoVentoSismo.html
Este arquivo apresenta um mapa interativo com uma análise comparativa entre ações de vento e ações sísmicas considerando um grande conjunto de tipologias estruturais, variando
Número de pavimentos, Classes de solo, Localização geográfica no Brasil. O mapa permite identificar padrões de predominância entre ações de vento e sismo em diferentes regiões.
Observação: Devido ao tamanho do arquivo, ele foi compactado em formato .rar. É necessário baixar e descompactar o arquivo antes de abrir o HTML.

# Mapa_RiscoSismico.html
Este arquivo apresenta um mapa interativo de risco sísmico para estruturas dimensionadas para a região Nordeste do Brasil.

A análise foi realizada considerando tipologias estruturais projetadas de acordo com normas brasileiras de dimensionamento estrutural, permitindo a avaliação espacial do risco sísmico associado a essas edificações.

Observação:
Este arquivo também está compactado em formato .rar devido ao seu tamanho e deve ser descompactado antes da visualização.
